# 阿列维／贝克塔什（Alevi–Bektaşi）

## 概述

阿列维（Alevi）是今日土耳其规模最大的宗教少数群体之一，估计约占人口一至两成，主要分布于安纳托利亚中东部、大城市与部分沿海地区，并随移民遍及欧洲。社群内部异质，常涵盖克孜勒巴什—阿列维、贝克塔什（Bektashi）等分支。多数阿列维自认穆斯林、尊崇《古兰经》，但礼仪形态与主流逊尼实践明显不同：百科描述其往往不按主流方式行礼前净洗、亦不按拉玛丹方式斋戒。信仰糅合古典苏菲与什叶元素，高度尊崇先知穆罕默德与阿里（Ali），强调实践的内在精神义理优于外在形式。集体崇拜以 *cem*（聚会礼）为核心，在 *cemevi*（聚会所）由 ***dede*** 主持；其中的神秘身体动作 *semah* 于 2010 年被联合国教科文组织列入人类非物质文化遗产代表作名录；公开文化层亦可见 ***nefes*** 灵性歌咏与 ***lokma*** 分享食等展示性叙述。本条目为教育性概览；**禁止用户主持 Cem／Semah**；不对入会、忏悔细节或限制性仪轨提供可复现步骤。**档位保持 B。**

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福与祈祷在阿列维语境中高度**社群化**：个人与真主、与阿里所象征的真理（*hakikat*）的关系，须在公平的聚会秩序中被见证。*Cem* 不仅是赞颂，也是自我省察与和解的场合——参与者在精神导师 ***dede*** 面前面对社群，修补人伦裂痕。功德表现为诚实、互惠、完成 *oniki hizmet*（十二项服务）所象征的责任分工，以及以 ***nefes*** 传授教义；***lokma*** 等分享食属公开文化／款待展示层，不可写成用户可「主持圣餐」的通关。贝克塔什传统作为苏菲教团，同样强调个人灵修与 *cem* 中男女同场的奉献礼仪。

## 典型仪式

### 1. Dede 与 *Cem*（聚会礼／âyîn-i cem）— 概念／非用户主持
- **场合**：传统上多在周四晚（称「周五夜」）举行；当代亦常改在周日等公共休息日。地点为 *cemevi* 或合宜的家屋空间。
- **主要步骤（概念层）**：由具谱系权威的 ***dede*** 主持；展开十二项服务；祈祷、短讲、*bağlama*／*saz* 伴奏的 *nefes*。**NO user Cem officiating**——公开描述止于结构与目的，不提供用户可完成的主持步骤。
- **物品**：弦乐器、灯火／蜡烛象征（*çerağ*）、供食与饮水等（细节因地方而异）。
- **谁来举行**：*dede* 领导；会众分担十二服务；**访客不得主持**。

### 2. *Semah* 与 *Nefes*（概念／文化传承层）
- **场合**：作为 *cem* 十二服务之一的内部 *semah*；亦有面向年轻世代文化传承的公开形式；***nefes*** 灵性歌咏贯穿教导。
- **主要步骤（概念层）**：理解 *semahçı* 在 *saz* 伴奏下以身体动作表达合一循环；教科文组织强调男女并肩同舞。**NO user Semah officiating**；**不提供**步法谱或内部口令。
- **物品**：仪式服装（因地方而异）、演奏空间与 *saz*。
- **谁来举行**：受训练的 *semahçı* 与乐师；文化传承场合遵循社群规范。

### 3. Lokma 文化展示与十二服务／*sohbet*（文化展示层）
- **场合**：公开款待与社群聚会中的 ***lokma*** 分享食文化展示；正式 *cem* 中的十二服务与收束 *sohbet*。
- **主要步骤（概念层）**：理解分享食作为款待／纪念文化展示；十二服务象征不同圣史角色。**Lokma 仅文化展示层**——不把分享食写成用户可主持的圣事通关。
- **物品**：分享食外观、象征性器具（视礼仪阶段而定）。
- **谁来举行**：被指定承担服务者与全体会众；文化展示遵循主办规范。

## 日常与节庆

城市中的 *cemevi* 已成为身份公开、教育与互助的枢纽；乡村则仍可能以巡回 *dede* 维系礼仪日历。历史压迫与污名使许多阿列维长期低调，当代则有政治与文化层面的可见度提升。贝克塔什教团总部近代迁至阿尔巴尼亚等地，巴尔干与土耳其的实践形态并不相同。

## 注意与尊重

阿列维与叙利亚阿拉维派（Alawite）名称相近但传统不同，勿混淆。勿擅自进入未对访客开放的 *cem*，勿摄录未经同意的仪式。*Semah* 的内部形式属于信徒实践，公开展演亦须尊重主办社群。**禁止任何用户主持 Cem／Semah。** 涉及饮食、性别同席与酒类象征时，以当地阿列维权威解释为准。
