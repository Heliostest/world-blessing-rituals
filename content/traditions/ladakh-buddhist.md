# 拉达克藏传佛教与山神祈福（Ladakh）

## 概述

**拉达克（Ladakh）** 位于印度北部高海拔地区，文化与藏区深度相连。公开概述记述：宗教以藏传佛教（格鲁、竹巴等公开存在）为核心；**gompa（寺院）** 公共层突出礼佛、转经与节庆；著名如 **Hemis Tsechu** 等寺院节，僧伽演出 **Cham** 面具舞供公众观礼。山神／地方灵常以 **Yullha** 等概念叙述，与苯教源流元素交织；亦有伊斯兰社群（如卡基尔等地）并置，本条目聚焦佛教—山神公开层。**Cham** 由僧伽主持、访客 viewing-only；**Yullha** 仅 CONCEPT；**不提供**密续修持细节或可冒充喇嘛的步骤——**users don't officiate**。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：通过礼佛、转经、供养僧伽与敬山神，积累功德并祈求旅途与越冬平安。功德贴近：支持气候变化下的水利／冰川关怀与本地解释权。访客的「福」体现为：高原反应量力而行，在 **Hemis** 等开放节庆谦逊观礼，不打扰辩经与法会——**users don't officiate**。

## 典型仪式

### 1. Hemis Tsechu 与 Cham 面具舞（僧伽观礼层）
- **场合**：Hemis 等寺院夏季／岁时公开节庆。
- **主要步骤（概念层）**：公开文化材料概述僧伽演出 **Cham** 面具舞、礼佛与公众聚集。**sangha viewing-only**；禁止模仿舞步、面具或密咒。
- **物品**：寺院广场、面具与仪仗外观（概念）。
- **谁来举行**：僧伽；访客仅观礼——**users don't officiate**。

### 2. Yullha 山神／地方灵（CONCEPT）
- **场合**：出行、换季、村社公共记述中的山神与地方灵敬礼。
- **主要步骤（概念层）**：理解 **Yullha** 等山神／领域神须受敬的公开叙述。**CONCEPT**；禁止复现献供操作细节或「召唤山神」。
- **物品**：从略。
- **谁来举行**：村社与寺院引导；外人不得主持。

### 3. Gompa 公共层：转经、玛尼堆与日常功德（公开层）
- **场合**：开放寺院与日常绕行。
- **主要步骤（概念层）**：理解顺时针转经、玛尼堆等公开实践。**gompa public layer**；止于访客可参与的礼貌层。
- **物品**：转经筒、玛尼石外观（概念）。
- **谁来举行**：信众个人与僧伽公开引导。
