# 水引（mizuhiki）

## 概述

水引（*mizuhiki*）是日本礼赠文化中的**装饰结绳工艺（A）**：以和纸捻成的细绳着色后，在礼金袋与礼盒上打成结饰，用于婚礼、出产、入学等**庆吊赠答的封缄**。长野县饭田市是有名的产业地，政府刊物 *Highlighting Japan* 记述其馈赠、庆吊与护符装饰等用途，以及鹤形水引等工艺造型。起源叙述须分层：饭田的产业叙述称遣隋使献礼曾系红白麻绳、红白配色自此而来——刊物原文用「据说（said to）」，属**产业传说层（B）**，不作史实；江户至明治间由发饰用 *motoyui*（元结）工艺发展出水引制作的路径**史料较实**。水引是**礼法与工艺**，**不是**神道或佛教的秘仪——本卡不并入 `shinto.md` 等宗教条目。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

水引的核心是**礼与连结**：结饰封缄礼物，把「郑重、未经启封的心意」系在赠礼之上；色彩与结形随庆事、吊事而异，是赠答礼法的可见语言（本卡仅作概念层科普，不展开各地细则）。它不在功德或神学框架内运作——没有回向与加持，所谓「祈福」只是把祝愿郑重地打进结里的心意。现代水引亦见于护符装饰与工艺创作，鹤形等造型寄托吉祥，仍属工艺象征层。

## 典型仪式

### 1. 礼金袋与赠答封缄（概念层）
- **场合**：婚礼、出产、入学毕业、岁暮中元等庆事赠答；吊事另用配色与结形。
- **主要步骤（概念层）**：按场合选礼金袋；水引在袋面打成结饰、封缄赠金；庆吊配色差异仅作科普，不写成硬性规则手册。
- **物品**：着色和纸捻绳（水引）、礼金袋、礼盒。
- **谁来举行**：赠礼人；市面亦有预制水引袋。

### 2. 工艺制作与传习（饭田等产地）
- **场合**：产地工房、体验教室、工艺展示。
- **主要步骤（概念层）**：捻纸、着色、依图打结成形；鹤形等造型为进阶工艺。
- **物品**：和纸捻绳与工具。
- **谁来举行**：产地职人与传习者；饭田市为著名产业地。

## 日常与节庆

水引嵌在日本赠答季节的节奏中：婚礼季与岁暮中元的礼盒上最常见，日常则见于各类祝仪袋。饭田等产地持续传习与创作，政府刊物介绍其现代用途与工艺造型。历史叙述分层表述：遣隋使红白绳说为产业传说（B），*motoyui* 到水引的近世工艺发展较可核验——文案与展示宜采保守说法。

## 注意与尊重

庆事与吊事的水引配色、结形礼法敏感，混用属失礼；细则以礼法指南与产地说明为准，勿凭印象替人定礼。勿把水引写成神道秘仪或宗教法物；起源传说勿当史实宣传。工艺体验与选购尊重产地与职人传承。

## 手机互动适合度（Three.js 评估草稿）

- **档位：** C 可做致敬小品（非真仪）
- **敏感度：** 低
- **判断：** 绕、穿、收的结绳手势适合手机致敬；定位 **A 工艺＋C 结绳微互动**，无秘仪风险。
- **若做成互动：** 手机手势练习（致敬小品，非礼法教程）：

1. 奶油暖色纸绳随指尖绕出第一个环。
2. 拖动收结，结形轻轻收紧、微微发亮。
3. 把完成的结系上「心愿封」，封入一句短愿。
4. 庆吊配色知识以一张科普卡出现，不做规则考试。
- **红线：** 默认庆事暖色；勿称神道秘仪；不把吊事配色做成可随意混搭的皮肤。
