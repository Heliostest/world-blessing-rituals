# 御守领受—返还（omamori）

## 概述

御守（*omamori*；袋装随身型亦称守札 *mamorifuda*）是**神社（亦见于寺院）颁发的随身守护象征（A）**：针对交通安全、学业、安产、家安等主题，装于织锦小袋中奉持。国学院 EOS 区分较大、多安于神棚或门柱的**神札（shinsatsu／ofuda）**与可随身的**守札／御守**；神社本厅英文导览强调御守非普通纪念品，而是承载神威的圣物，宜自持或赠亲友。仓库 `shinto.md` 已述领受与岁末返还焚纳。本卡**聚焦「领受→佩持→期末返还」时间循环**，不新建神道总卡，也不做拆袋看内部的玩法。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

御守循环的心意是**有期限的相伴与感谢的归还**：领受是把守护主题带在身上；佩持约一年或事成；期满送到古札纳所／纳札箱等处返还焚纳（地方名称或有异），而不是永久收藏或随意丢弃。它不是「买到永久 buff」，也没有拆开验真的环节——**勿拆开看内部**是公开尊重规范。返还带着一句感谢，循环才完整。

## 典型仪式

### 1. 领受—佩持—返还（概念层）
- **场合**：初诣、旅行出发、人生转折；岁末或事成后返还。
- **主要步骤（概念层）**：在社务所说明需求并领受御守；恭敬放入包中或随身；**约一年或事成后**送至神社指定纳所返还（习惯差：**待核实**是否全国统一「必须一年」）。勿拆袋；废旧勿当垃圾丢弃。
- **物品**：袋装御守；纳札／古札纳所（概念）。
- **谁来举行**：神社授与；信众奉持与返还。

## 日常与节庆

御守是**长线持有、节点归还**的实践：日常默默佩戴，正月换御守与岁末返还是常见节奏，但各社习惯不尽相同——「必须满一年」是否全国规范仍 **待核实**，产品文案宜写「约一年或依各社说明」。与绘马墙的「获得—书写—悬挂」可并列为获得—持有—感谢闭环，但物件不同。

## 注意与尊重

**禁止拆袋**小游戏或「看内部」。不售「真神威」暗示；不模仿秘符制作。废旧返还，不随手丢弃。与神札／ofuda 区分尺寸与安置（EOS）。文案忌通关语与永久增益承诺。

- **档位：** C 可做致敬小品（非真仪）

- **判断：** 「选主题袋→佩戴计日→到期虚拟返还并写感谢」适合时间循环叙事，与绘马一次书写形成互补。
- **若做成互动：** 手机手势练习（致敬小品，非神社实务）：

1. 奶油色社务所小桌，几只主题小袋（旅安、学业、家安……）。

4. 界面留一句：谢谢这一程。
- **红线：** 禁止拆袋；不售真神威；不做永久 buff／通关；到期提醒可关、非强迫；不称完成正式仪轨；不做功德计数。
