# 审阅备注与使用限制

本次检查的是仓库现有文字的可用性。它既不是新增研究，也不是以实现效果倒推材料充分；“齐备”始终只对应记录中的 selectedDisplay。原始传统卡与原 A／B／C 档位保留。

## 资料与产品对应需要单列的问题

### 燃灯会与圆佛教卡

`packages/app/src/scene-library.tsx:70` 将燃灯上浮关联到 `won-buddhism`。但圆佛教卡描述的是一圆相、四恩、随时禅与周日法会；仓库候选研究 `specs/2026-09-20-daily-micro-rituals-candidates.md:303–315` 则以韩国佛诞公开燃灯会／莲灯为对象。现有文字没有说明为什么二者可建立此归属。

此外，研究写的是制作、提灯、点亮与原创“加入灯海”，没有明确“上浮”的文化动作依据。因此 S01 中燃灯上浮评为范围待厘清。所需补写是资料对应与原创动作身份说明，不是开发新的漂浮动画。

### 雅兹迪卡中的边界冲突

`content/traditions/yazidi.md:5` 规定“高度敏感，仅供教育理解，不提供任何 how-to”；典型仪式还要求油灯停留在 CONCEPT，不提供点灯／内部步骤。但手机评估段又列出结新结、解旧结与点灯动作。

本次不从拟手势段自动推导许可，也不更改档位。应先确定允许的公开图文对象，澄清这些动作究竟是不得操作的真实实践还是已与真实实践分开的原创意象。对应材料状态为范围待厘清，不把受限仪轨脚本列为待补资料。

### 乔尔卡中的身份文字冲突

`content/traditions/chol-traditional.md:5` 同时写“Chol，自称为 Yokot'anob 等”与“与约科坦（塔巴斯科）……区分”。仓库另一条约科坦卡以 Yokot'an 为对象。材料内的命名与区分关系需要核对，现有文本不能直接用作一致的身份介绍。

本次只记录仓库文字冲突，不提出未经外部验证的正确译名或民族归属。应核对公开社群／语言资料再修订；在核对前不把此卡判为可直接编辑文化介绍。

## 普遍缺口的处理

- “物品：从略”没有满足物件材质维度；不能把国家、族群或建筑类别名称当作具体器型说明。
- “走近、点亮、放入、漂远”是方向摘要；即使已有代码，也不能替代起始状态、作用对象和结束状态的文字。
- B 档不要求用户动作或仪式主持程序。静态图文的过程可不适用，但仍要明确配图／地图对象与观看范围；若只有地理伦理概述，开发环境展示所需文字仍可能不足。
- 每条有三五个 URL 不等于已建立“这件物品／这项过程—对应来源”的关系，不能据 URL 数量自动通过 provenance。
- 不将没有精确测绘尺寸、真实音频文件或完成模型当作本轮材料不足；相对比例、音色方向与原创场景取舍用清楚文字即可。
- 历史起源仍待核实的内容不一定阻断现代器物切片：可先限定现代公开形制与用途，省去没有依据的起源年。

## 复核与可追溯性

每条记录保留原文短引、真实行号及读取文件。构建脚本检查库存覆盖、重复 ID、批次、八维枚举、齐备门槛、引用行号与引文是否实际存在。JSON 的 sourceSha256 保存审阅时文件指纹，后续原卡改动时应复评引用和结论。

这种检查能发现台账与文本不一致，不能代替语义审阅或外部事实验证。本轮由分组逐项审阅形成记录，主审另复核齐备与范围待厘清项、已接入体验，以及若干一般条目。后续需要研究补齐的事项已列在各条 nextWriting，未被悄然填成事实。
