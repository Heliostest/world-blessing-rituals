# 展示材料齐备性评估口径

评估日期：2026-10-04。对象：现有 156 个 C 档、342 个 B 档传统条目，另单列 8 个已接入 App 的体验。后者包含与传统卡相同的切片，单独复核产品资料，不计入 498 个传统候选。725 个传统条目中的 227 个 A 档及比较总览不进入此次展示开发候选评估。

本次评估阅读仓库现有文字与参考资料，判断材料是否足以编写后续设计规格。不是史实重新验证、图片授权审核或上线许可。既有 Notebook 通过状态、来源链接数量和正文长度均不能代替本次齐备性判断。图片、模型、贴图、音频文件、Three.js 代码及交互脚本的实现不作为扣分项目。

## 评估单位与范围

传统卡片往往包含多个习俗。每条评估必须选定卡片已允许的一个公开展示切片，写清 selectedDisplay；不能把限制性仪式的细节当作应补齐资料。选择图文介绍不会自动证明该条目已足以支撑后续场景开发。B 档仅描述可见物件、环境和观察到的公共过程，不要求用户主持动作；公开资格与观看边界要明确。

按 slug 排序：C 档每批最多 20 项，8 批；B 档每批最多 20 项，18 批；App 已接入体验单列第 27 批。逐项语义审读后记账，不用关键词命中直接生成齐备结论。

## 八个文字维度

各维度取 0（缺失／与选择切片无关）、1（只有名称、概念或仍有关键歧义）、2（具体且可用于编写规格）。合理不适用记 null，并说明理由；不适用不用于提高总分。

| 键 | 维度 | 达到 2 所需文字 |
| --- | --- | --- |
| context | 身份与文化范围 | 对应名称、地域、时代或当代语境、场合与意义；分清传统与产品改编，不混不同地方 |
| objects | 物件与材质形制 | 主次物件、具体材料、轮廓／部件关系、可见表面或制作特征；仅列物名为 1，未明确材料不能猜测 |
| space | 环境与空间关系 | 场所类型、物件位置、背景要素、人与物关系或观看位置；仅“寺院／村落／海边”通常为 1 |
| sequence | 过程与状态变化 | C 档有可理解的起始—动作／对象—变化—终止文字；B 档描述公开可观察过程或静态观看范围，不补真实主持脚本 |
| sensory | 可见／可闻表现 | 该切片具体的运动、光、质感、声音等文字；实际声画文件不要求，泛泛“安静暖色”为 1 |
| variants | 变体与选择 | 标明具体选用地区／器型／时段与不能通用的部分；可明确说明原创取舍，不要求穷尽所有变体 |
| boundaries | 展示资格与改编边界 | 哪些可见、可表达、由谁进行；哪些不可模拟；具体限制与选择切片一致 |
| provenance | 事实与参考的对应 | 存在明确对应此切片的来源说明；只有参考 URL 列表为 1，不能宣称已读过或验证外网来源 |

不要求精确历史尺寸、秘传文字、私密配方、献牲步骤或完整礼拜。若没有实测参数，须把比例、配色、时间等明确留作产品设计决定；缺少毫米尺寸本身不是不齐备。

## 两个独立结论

- narrativeReady：是否可基于现有文字编辑一张有边界的文化介绍卡，取 true/false。它不表示后续开发材料齐备。
- readiness：针对后续展示设计与开发文字基础，取 ready（文字齐备）、partial（部分齐备，需补关键项）、insufficient（多项核心描述缺失）、scope_blocked（当前无法从文字选出明确可展示切片）。

ready 必须 context、objects、space、sequence、variants、boundaries、provenance 均为 2，sensory 至少 1，且无阻断性矛盾。静态图文 sequence 可合理不适用，但不能同时声称动态展示已齐备。partial 至少已有明确范围、物件或过程中的一个具体基础，仍有未满足的核心维度；只剩地理、伦理及“从略”的条目通常 insufficient。切片限制不清、跨文化归属矛盾未解决时可 scope_blocked。不能因有一段拟手势列表就评为 ready。

## 每条评估的证据与补写要求

评估记录必须包含 slug、title、grade、batchId、selectedDisplay、readiness、narrativeReady、dimensions、evidence、gaps、nextWriting、sourceFiles。evidence 至少两条带仓库路径、有效行号和短原文的证据，指出已有信息及不足依据；引用不足时使用真实的“物品：从略”等，不虚构原文。gaps 与 nextWriting 必须与此切片对应，不能只是八项通用模板。每条至少一条具体补写任务；ready 项可写非阻断性后续编辑任务。

没有补做研究就不能填写新的民俗事实。建议写成“补选定器物的材质、部件关系并给出来源”，而不是未经证实地写入材料。共性缺口允许复用，但必须带该条目的具体器物／环境／范围对象。评分总和仅供统计，不以总分抵消核心缺口。
