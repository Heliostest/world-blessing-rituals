# 后续文字补写与复评模板

本模板用于完成各批报告的 nextWriting，不要求实现模型、场景或脚本。它不能取代研究资料；模板中的空位需要有依据地填写。

## 1. 先固定一项展示

- 条目 ID 与批次：
- 选定习俗／器物／公共场所切片：
- 具体地域、年代或当代场合：
- 观者／参与者身份及可展示范围：
- 展示定位：图文介绍、静态器物、公共环境或原创短体验。
- 不采用同卡哪些其他仪式或地方变体，原因是什么：

如果同一张卡兼述几种习俗，先选一项。图文展示的可用文字不等于整个传统足以开发场景。B 档保持观看与说明资格，不补用户主持礼仪。

## 2. 分清描述的性质

| 描述 | 类型 | 对应仓库来源／外部资料具体段落 | 尚存不确定性 |
| --- | --- | --- | --- |
| 地域、场合、物件用途 | 文化事实／当地公开说明 |  |  |
| 轮廓、部件、材质 | 实物观察／文字资料 |  |  |
| 比例、背景、配色、节奏 | 原创产品决定或有据的参照 |  |  |

不得把产品决定写成传统规范；一张来自某处的图片不能继承另一件馆藏的年代、地域或宗派。暂没有资料时明确留作待研究，不能让生成图或程序默认值补成“事实”。

## 3. 器物文字

为主物件及必要配件分别写出：

1. 整体轮廓、主要部件、空腔／开口／层次及连接关系。
2. 材料和表面：哪些部位由何种材料构成，能观察到什么；未确认的木种、花种、文字保持未知。
3. 识别所必需的相对比例与朝向。精确尺寸不是本轮要求，原创比例需注明。
4. 物件是悬挂、摆放、手持还是漂浮；支撑或接触在哪里。

不充分：“有纸鹤／木牌／秋千”。较充分的文字应让设计者知道有哪些部分、怎样相连、什么部位薄或厚、从哪一方向看。既有纸鹤研究中的三角翼、细颈尾、折返喙和薄纸叠层就是部件描述；它仍不能代替中间折叠状态。

## 4. 环境文字

- 地点类型、可见边界与观看位置。
- 主体、配件与背景的相对位置。
- 地面／水面／墙面／树枝等支撑要素及人与物的关系。
- 有依据的时间／光线／季节；原创舞台部分单列。

不需要提出渲染算法，也不需要复原不准入的空间。选择静态介绍卡时写清配图应说明的对象与范围即可；若之后扩成环境展示，再补该环境的具体文字。

| 变化 |  |  |  |  |  |

C 档需要可理解的动作与起止状态。B 档只描述公共可观察过程；静态对象不需要编造运动，可解释不适用。不能把“点亮”“漂远”“上色”一个动词直接当完整过程，也不需要在此确定代码、计时器、手势识别或动画库。

## 6. 文字验收

- 另一位设计者只读这份说明，能否画出主要物件与相互位置，写出展示的起止状态？
- 是否仍需猜主要材质、器型、地点、归属或谁可做动作？关键项有猜测则仍未齐备。
- 是否把不可获得的主持脚本或封闭细节误列为必须补齐？应先缩小为允许的公开展示切片。
- 关键文化陈述及器物参照是否各有对应来源？仅列链接不能通过来源对应维度。
- 是否明确区分真实实践、器物观察与原创设计？是否保留地方差异与已知不确定性？

补写完成后按 [rubric.md](rubric.md) 逐项复评，不以增加字数或素材数量自动升级。
