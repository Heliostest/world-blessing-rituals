# 本地优先与统一场景宿主实施计划

目标：用户进入场景不等待内容服务器；后台准备的完整包在下一次挂载试用，首帧成功后确认。统一懒加载、暂停/恢复、减少动画、失败与释放接口。

授权：用户已同意上一轮建议的第 1、2 项；本轮在现有架构分支继续，不重复审批、不合并或推送。保留目前未提交改动。按 writing-plans / executing-plans 在当前会话实施，最后独立审查。

设计：`load()` 只读取准备完成的缓存包、已确认缓存包、内置包；`prepareUpdate()` 单独访问远端，完整校验并成功缓存后登记 pending，不能覆盖 confirmed。旧数组元数据兼容读取；确定性内容缺陷隔离到有界 rejected 列表，内容变更后可再次尝试，临时 GPU/宿主错误允许下次重试。缓存缺失不能启动前台网络回补。宿主负责异步加载竞态、可见性、状态转发、AbortSignal 和幂等释放，引擎负责 GPU 与具体输入。

- [x] 内容服务：测试首屏不触网、完整准备/首帧确认、旧元数据、坏包与缺失缓存、取消与并发更新；实现两阶段加载和串行元数据修改。
- [x] 平台缓存：增加只读缓存接口，Web 不重复写二进制来更新 LRU；Native 增加独立只读缓存 action，不等待后台下载队列。
- [x] 场景宿主：新增 `packages/scene-runtime`，测试延迟加载后卸载、失败释放、暂停/恢复、减少动画、可见性与独立引擎注册。
- [x] 木鱼接入：注册内置引擎、React 使用统一宿主；首帧后触发后台准备，卸载取消，不改变业务计数或输入规则。
- [x] 更新真实浏览器测试，验证慢清单/慢下载下即时使用缓存、下一次进入才切换、错误包回退、原有触控/队列。
- [x] 内容与宿主单元测试、全仓验证、Web/Expo 打包、独立审查和文档。

重点边界：后台结果晚于卸载、缓存被系统清除、试用失败与后台写入交错、懒加载期间属性变化、宿主在隐藏页面挂载。没有新增云服务或承诺真机验证；通用引擎注册不等于开放任意远端代码，当前可发布内容仍限 woodfish@1。

验证记录：全仓 76 项单元测试与 Web / Expo Android+iOS 嵌入构建通过。独立复审发现的临时失败持久隔离、缓存写入失败仍登记待用两项问题均修复，并补充回归；定向复审通过。浏览器测试改为等待实际 IndexedDB 查询结果，避免本机 Playwright 将 Promise 提前当作满足条件。
