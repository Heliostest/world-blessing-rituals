# 场景内容分发实施计划

用户已明确：模型、贴图、音效、文案及现有交互参数独立更新，新增交互代码不属于内容包。按已授权范围在本任务实施，不创建云端服务、不发布生产内容、不修改奖励与存档规则。

设计依据：[架构方案](../specs/2026-09-21-scene-content-architecture-design.md)。本轮落地内容分发主链路；通用动态仪式目录、存档 v2、EAS Update 留作后续独立需求。

- [x] `packages/content`：严格内容契约、哈希、候选版本选择、确认/失败回退；测试错误配置、坏文件、断网、取消和版本原子提交。
- [x] Web IndexedDB 缓存和 Native FileSystem 适配；缓存预算、按哈希复用、原生串行下载、元数据与存档隔离。文件 URI 交给 DOM，避免大型 Base64 props。真机验收待进行。
- [x] 发布脚本生成内容哈希资源和 manifest；Vite/Expo 仅复制显式启动清单。轻量内置 GLB 1.68 MiB，高清版置于独立发布目录。
- [x] 木鱼通过内容服务加载；包提供绑定、半径/握点、灯光和动作参数。挂载实例固定版本，成功绘制后确认；失败回退历史版本和独立内置包。
- [x] 本地 HTTP 内容服务与端到端测试：更新、缓存、断网、坏包、不兼容包、首帧失败、挂载版本固定和原有输入/音效回归。
- [x] 全套 63 项测试、模型检查、生产构建、Expo Android/iOS 嵌入打包、独立审查；另验证生产预览内置轻量版与着色器回退竞态。真机缓存 URI 验收和 CDN 部署未进行。

缓存边界：普通缓存目标 256 MiB，单资源上限 64 MiB，清理不涉及用户记录。内置包不参与清理，当前场景持有内存资源至卸载；磁盘缓存可被淘汰，历史描述不保证文件永久存在。内容包只描述现有引擎，不含 JS/HTML。用户保留离线包和跨会话依赖保护留作后续。

本轮各仪式目标步数、奖励和稳定 ID 保持由 core 定义，因此无需改变现有存档。正在使用的木鱼内容不会因后台目录刷新而更换；跨重启继续原有进度，视觉包可换为兼容版本，玩法规则仍是原值。完整跨重启内容版本固定属于后续动态仪式目录阶段。
