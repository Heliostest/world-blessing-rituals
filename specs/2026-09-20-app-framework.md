# 奶油祈福 App 框架

用户已要求直接实现整体框架，沿用 HistoryCard 的 Expo 54 / React Native 0.81.5 / React 19.1 / TypeScript / Vite 路线。本轮不新增 Three.js 场景。

## 范围
- 四个主页面：今日、心愿、小天地、我的；仪式、心愿编辑、详情使用独立页。
- 三种静态仪式入口：木鱼、纸鹤、心愿灯，使用简单点击步骤验证流程。
- 心愿可记录进展、标记实现、还愿、归档与恢复。还愿只发纪念物。
- 核心业务为纯 TypeScript；共享 React UI；平台提供异步存储和震动接口。
- 本地版本化存档、校验、串行保存和失败重试。无账号和云同步。
- 原对话读取只有文字、没有图片附件。素材槽暂用明确的占位图形，收到原图后替换；不声称已复用原图。
- 旧场景和手势保留在开发工具入口，不进入主体验包。

## 实施顺序
1. 核心业务测试与状态模型：心愿状态、仪式进度、幂等奖励。
2. 存储协议、恢复校验、保存队列。
3. 共享页面与奶油色设计变量、静态素材接口。
4. Vite 与 Expo 容器接入，安全区、返回键和前后台。
5. 业务测试、网页构建、Expo 类型与打包检查、浏览器交互验证。

## 验收
新增心愿 → 记一笔 → 标记实现 → 还愿 → 查看收藏 → 重开保留。
仪式中途退出可继续；重复完成不重复奖励；归档恢复保留状态；坏存档不被空数据覆盖；保存失败可重试。

本设计取代旧试点规格中“不设功德和养成”的产品限制，研究资料本身保持不变。
