# 班图世界观与乌班图（Ubuntu）

## 概述

“班图”宽泛指使用班图语支的中、东、南部非洲广大人群；**Ubuntu**（及相关词如绍纳语 *hunhu*）是其中广为人知的伦理—形上概念，常译为“通过他人而成其为人”。它不是单一教派的礼拜手册，却深刻塑造祝福、和解与祖先相关实践：人与在世者、已逝的“活着的死者”（祖先）以及未出生者共同构成道德共同体。本条目讨论这一共享取向如何理解祈福与修复，而非声称所有班图社会仪轨同一。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

经典表述接近“人唯通过他人才成为人”。人格包括对祖先的义务与对后代的责任。祝福常表现为关系修复：疾病、冲突或灾厄可能被理解为社会—祖先纽带的撕裂，需礼仪与商谈使之复原。功德近于慷慨、款待、调停与记念祖先，而非个人积攒可转让的“分数”。和解仪式中，祖先被请求见证并圣化协议。现代南非转型期曾把 Ubuntu 用作公共伦理话语，但学者提醒勿将其简化为无冲突的“彩虹修辞”，而忽略更复杂的历史与灵性层面。

## 典型仪式

### 1. 祖先沟通与家祭（概要）
- **场合**：丧后安顿、求指引、家庭危机。
- **主要步骤**：家族在指定处所祈祷、奠酒或献食，向祖先报告并请求护佑；细节因族群而异，仅概念说明。
- **物品**：饮料、食物、象征物。
- **谁来举行**：家长、长老；有时延请传统医者。

### 2. 和解与复原礼仪
- **场合**：人际冲突、社区创伤后。
- **主要步骤**：公开陈述、调解、象征性分享；吁请祖先认可和平。不涉及具体祭牲操作说明。
- **物品**：共享饮食等。
- **谁来举行**：长老议会、调解人、相关家族。

### 3. 生命周期祝福
- **场合**：命名、成年、婚礼、葬礼。
- **主要步骤**：以歌、词、动作把个人嵌入谱系；祈求多产、保护与善名。
- **物品**：视地方传统而定的服饰与食物。
- **谁来举行**：亲属与仪式专家。

## 日常与节庆

款待访客、分享食物、参与丧礼劳作，本身即是 Ubuntu 的日常演练。许多社区并行基督教礼拜与祖先礼仪。传统医者（各地称谓不同）在诊断与礼仪指导中扮演角色，但其训练与禁戒属于专业传承。

比较阅读时，可将 Ubuntu 的关系性福佑，与佛教功德回向、犹太 *tzedakah* 的公义施舍对照：相似处在于强调他者，差异在于祖先本体论与人观。

在丧礼互助团与邻里探访中，Ubuntu 往往先于理论出现：一碗食物、一夜守灵、一句致歉，比口号更能说明何谓“通过他人而成”。

## 注意与尊重

勿把 Ubuntu 商品化为企业口号而剥离其祖先与土地伦理。葬礼与招魂类仪式常有严格资格。跨文化工作者应避免用单一祖鲁／科萨表述覆盖所有班图社会。本档案不提供治疗处方或祭牲步骤。
