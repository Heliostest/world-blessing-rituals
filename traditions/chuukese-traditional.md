# 楚克传统信仰与村社祈福余绪（Chuukese／Truk）

## 概述

**楚克人（Chuukese；旧称 Truk）** 居住于密克罗尼西亚联邦楚克州——珊瑚环礁环抱多座火山高岛的潟湖群岛。Pulotu 与区域文化综述指出：皈依基督教前，崇拜对象包括天空神、神化高等首领与多样善恶诸灵；今日天主教与新教（含公理会传统）占主导，祖先灵魂影响事态、精灵与附体等前基督教要素仍常与教会实践交织。教堂是聚落最醒目的神圣建筑；与传说相关的地点仍可被视为有力圣地。本条目为教育概览；**不提供**法术配方、占卜步骤、附体脚本或任何可冒充仪式专家的程序。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：在教会日历与村社宴饮竞争中，通过礼拜、初熟／丰收感恩的教会化形式，巩固航海—农作共同体；前基督教层则以祖先与地方灵解释保护与灾祸。功德贴近：支持堂区头衔竞争中的慈善与事工、葬礼互助、尊重圣地。访客的「福」体现为：尊重楚克潟湖的生态脆弱与习惯法，而非只拍「攻壳」式热带明信片。

- **场合**：主日、圣诞、复活节；竞争性宴饮并入教会节期的公开叙述。

- **物品**：教堂外观（概念）。

### 2. 祖先与地方灵叙事（概念层）
- **场合**：疾病解释、家庭护佑、传说圣地。
- **主要步骤（概念层）**：理解祖先仍可影响人事的公开信念。**禁止**招魂或附体游戏。
- **物品**：从略。
- **谁来举行**：长辈与家庭。

### 3. 航海—渔捞相关戒忌余绪（概念层）
- **场合**：出海与礁湖资源利用。
- **主要步骤（概念层）**：区域综述提及传统专责者曾司天气、丰饶与战事顺利等祈请。**止于概念**。
- **物品**：从略。
- **谁来举行**：渔人与长老。

## 日常与节庆

楚克与波纳佩、雅浦同属密克罗尼西亚联邦但历史与语言不同。优先 Pulotu、everyculture 区域条目与楚克人自身叙述。
