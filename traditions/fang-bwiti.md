# 芳人／布维蒂祖灵—基督交融传统（Fang／Bwiti）

## 概述

**芳人（Fang）** 主要分布于加蓬、赤道几内亚与喀麦隆南部雨林地带；大英百科指出，一种称为 **Bwiti（布维蒂）** 的交融宗教在 20 世纪初基于更早的秘密会社传统成形，并在芳人中促进社群团结。Bwiti 将祖先崇拜与基督教象征（如耶稣、圣母等公开叙述中的形象）及先知领导相结合，亦见于非洲宗教综述中的“新宗教／独立教会”类型。公开学术史亦讨论仪式中使用的 **iboga（Tabernanthe iboga）** 植物与异象传统——此属高度敏感的入会／医疗语境。本条目仅为教育概念概览；**绝不提供**入会程序、植物剂量、服用方法、通宵仪轨脚本或任何可复现的致幻／成巫师步骤。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：在祖先与基督象征交织的宇宙中，通过社群仪礼、音乐与对祖灵的正确关系，使个人获得生命方向、疾病得慰、族群在殖民与现代变迁中保持连续。百科强调此类教会试图在剧烈社会变迁中维持共同体与连续性。功德贴近：尊重入会边界、支持家族与会众、以伦理生活回应祖灵与信仰教导。访客的「福」体现为：把 Bwiti 放在非洲宗教史与文化权利语境中理解，而非“雨林迷幻旅游产品”。

- **物品**：会堂／礼仪空间外观、乐器外观（远观）。
- **谁来举行**：先知／礼仪领袖与会众；外人未经邀请不得闯入。

- **谁来举行**：经授权的社群内部人员；游客与研究者皆须严格伦理边界。

### 3. 生命礼仪与当代加蓬公共文化层
- **场合**：命名、婚丧、国家文化表述与博物馆语境中的艺术、面具与音乐遗产。

- **谁来举行**：家庭、教会／会众与文化机构。
