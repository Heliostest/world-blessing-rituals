# 夏威夷原住民祈福与 hoʻokupu／makahiki

## 概述

夏威夷原住民宗教传统以对 **akua**（神祇）、**ʻAumakua**（家族守护祖灵）与土地—海洋关系的敬意为核心，四大主神常举 Kāne、Kanaloa、Kū、Lono。公开文化叙述强调 **Oli**（颂诗）、**Hula Kahiko**（古典胡拉）、**Heiau**（神庙遗址／圣地）与 **ʻAumakua**；**Kumu Hula／Kahuna viewing — users don't officiate**（胡拉教师／祭司传统仅观礼——用户不主持）。美国国家公园署等公开资料详述的 **Makahiki** 与 **Hoʻokupu** 奉献仍为重要季节／互惠层。本条目仅高层次介绍公开文化叙述；**不提供**可演唱／可复现的专属文本或动作教程。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福与丰产、和解、正确对待 *āina*（土地）相连。Hoʻokupu 表达尊重与互惠；Makahiki 承载和平季与贡奉再分配叙事。功德／威望体现在履行贡奉、遵守 *kapu*、维护谱系知识与社区庆典。访客的「福」体现为：尊重康族（*kānaka maoli*）文化监护人权威；**users don't officiate**。

## 典型仪式

### 1. Oli 与 Hula Kahiko（概念／观礼层）
- **场合**：文化节、学校与社区公开展演；圣地相关纪念。
- **主要步骤（概念层）**：公开场合可见的 **Oli** 与 **Hula Kahiko** 属活态文化遗产，但谱系、编舞与适用场合由 *kumu* 与家族决定。本档案只承认其存在与尊严，**不提供**歌词、动作或「如何开始跳」。
- **物品**：依各传统的服饰与乐器（公开展演场合）。
- **谁来举行**：经认可的实践者；观众肃立、勿跟跳除非受邀。

### 2. Heiau 与 ʻAumakua（圣地／概念层）
- **场合**：**Heiau** 遗址相关纪念；家庭与宗族层面的 **ʻAumakua** 关系。
- **主要步骤（概念层）**：理解圣地尊严与家族守护祖灵的公开概念。**止于概念／远观**；不提供请神或进入核心区操作。
- **物品**：从略。
- **谁来举行**：文化实践者与家族；用户不主持。

### 3. Kumu Hula／Kahuna viewing — users don't officiate（观礼层）
- **场合**：公开展演、文化中心、Makahiki 社区活动。
- **主要步骤（概念层）**：**Kumu Hula／Kahuna viewing — users don't officiate**。理解教师／祭司职分的公开存在。**禁止**冒充 kumu／kahuna 或完成贡奉通关。
- **物品**：从略。
- **谁来举行**：经认可的 kumu／文化实践者；用户仅观礼。

## 日常与节庆

当代夏威夷可见学校 Makahiki 运动会、国家历史公园的文化解说，以及火山等与 Pele 相关的民间敬意。旅游场的「卢奥宴」表演不等于完整宗教生活。

## 注意与尊重

勿擅自取石、取沙或留下「堆石纪念」。勿录音专属 oli 或在未开放的 heiau 核心区拍摄仪式。Hula／oli 的商业挪用与不当模仿是长期伤害，须经许可。**Users don't officiate.**
