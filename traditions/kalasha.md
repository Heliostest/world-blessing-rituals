# 卡拉什（Kalasha / Kalash）

## 概述

卡拉什人是巴基斯坦开伯尔—普赫图赫瓦省奇特拉尔（Chitral）地区本布勒特、伦布尔与比里尔等山谷中的小型印欧语系原住民族群，人口约数千，是该区域少数仍延续前伊斯兰多神—万物有灵与祖先崇拜传统的共同体。其宗教生活围绕季节性节庆、圣地祭坛、洁净观念与畜牧—农作节律展开；主要神祇叙述中常见创造者、山谷守护神、丰饶与家屋相关神灵，以及冬至大节期间造访的宾客神等。联合国教科文组织世界遗产中心已将「卡拉什山谷文化景观」列入巴基斯坦申报预备名单，强调其作为持续运行的活态文化系统。本条目为教育性概览，不对献牲程序、洁净禁忌的执行细节或限制性仪轨提供操作说明。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福与感谢深深嵌入**岁时循环**：春季迎接乳汁与新生、夏秋祈求麦作丰收、隆冬结束田间劳作并以宴乐与仪典迎接新年与神灵造访。人与神、人与畜群、人与山谷圣地之间维持互惠：神灵护佑牧群与收成，人类以节庆、供奉、歌舞与共同体规则回应。祖先记忆可通过墓地木雕形象（公开文献所称 *gandao* 一类纪念像）等物质文化延续。「功德」表现为遵守社群习俗法、完成季节感谢、维系圣地与节庆的公共秩序，而非个人积德簿记。男子畜牧与女子农作的劳动分工亦与神圣—洁净叙事相关，公开讨论应避免猎奇化性别规范。

## 典型仪式

### 1. 乔希节（Joshi / Chilam Joshi，春季节庆）
- **场合**：约五月，迎接春天、祝福畜群与社群更新。
- **主要步骤（概念层）**：公开叙述包括「乳日」等环节——以保存的乳汁举行奠酒式谢恩；伴随歌舞与共同体欢庆。细节因山谷而异，止于概念层。
- **物品**：乳制品、节庆服饰、圣地／公共节庆空间。
- **谁来举行**：卡拉什社群成员；礼仪知识由长老、宗教职能者（文献中常提及 qazi、萨满式通神者等角色）传承。

### 2. 乌乔／乌查节（Uchaw / Uchau）与地方秋收相关仪典
- **场合**：约八月末，祈求或感谢小麦等作物收成；比里尔山谷另有秋季 *Pul*／*Poh* 等地方节期。
- **主要步骤（概念层）**：歌舞、谢神与共同体聚会，将丰收纳入与牧神、农作神灵的互惠叙述。
- **物品**：谷物与节庆供物（因地而异）。
- **谁来举行**：各山谷社群。

### 3. 乔莫斯节（Chawmos / Chaumos，冬至大节）
- **场合**：约十二月冬至前后，为期逾两周，被视为最重要、最复杂的年度节庆，标志农事结束并迎接新年；传统叙述中宾客神（如 Balumain／Balimain）自神话故乡造访。
- **主要步骤（概念层）**：音乐、舞蹈、净化与共同体宴饮；文献记载包含畜牧献牲作为节庆消费与宗教表达的一部分——**本档案仅说明其谢神与岁末更新的宇宙观意义，不提供宰杀或程序化操作说明**。
- **物品**：乐器、节庆服装、圣地与祭坛空间。
- **谁来举行**：全社群参与；仪式专责者指导关键宗教环节。

## 日常与节庆

日常宗教生活分布于家屋相关神灵（如家庭保护叙事中的 Jestak 等）、开敞祭坛与季节迁移的牧道之间。妇女相对周边穆斯林社会有更大公共可见度，传统服饰与节庆舞蹈亦是文化认同标志。近数十年道路、旅游、木材开发与宗教改宗压力改变山谷生态；学校与遗产申报带来新的可见性，也带来文化商品化风险。

## 注意与尊重

卡拉什人是人口极少的宗教少数群体，拍摄面容、葬礼、圣地与妇女须严格征得同意。勿将「异教／卡菲尔」等历史他称用作贬损，勿在节庆中强行介入献牲或洁净区域。旅游消费应惠及社群并遵守地方长老会与巴基斯坦相关法规。预备遗产地位强调社群参与式保护，外人不应盗用仪式知识或圣物意象于商业产品。
