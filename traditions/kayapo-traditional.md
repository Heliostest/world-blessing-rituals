# 卡亚波／梅本戈克雷祈福与命名礼仪概观（Kayapó／Mebêngôkre）

## 概述

**卡亚波人（Kayapó；自称常作 Mebêngôkre）** 为巴西中部—亚马孙过渡带的热—图皮语系原住民族之一，以身体彩绘、大型命名礼仪与环境权利运动闻名。Socioambiental 与 everyculture 等公开材料记述：仪式将自然、社会与宇宙观相连；重大礼仪确认个人名字，农渔猎与日食月食等亦有仪典；成套「扩展美丽」的身体装饰礼仪标示年龄级过渡。名字常自自然借入，萨满可自自然灵学习新歌与新名，再于大型命名礼引入文化。来世叙事中有死者村，男女权限不同。本条目为教育概览；**不提供**入会步骤、身体彩绘仪式配方、萨满歌诀或任何可冒充仪式专家的程序。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：通过命名与季节礼仪，把「野生／反社会」力量社会化，使人与动物—自然维持可生存的互惠。功德贴近：完成年龄级公共义务、捍卫领地免受非法开采、在礼仪中分享食物。访客的「福」体现为：支持卡亚波土地与气候正义，而非消费「裸体部落」刻板印象。
