# 满族萨满与祭神祭天传统

## 概述

**满族（Manchu）** 属通古斯语族，历史上以东北为根基并建立清朝。英语 *shaman* 一词即源自满—通古斯语 *šaman*（「知者」），大英百科以此讨论北亚萨满现象的词源与类型。满族实践常区分面向天神、祖先与氏族神灵的**家祭／堂子类礼仪**，以及涉及动物／英雄神灵、有时伴随通神表演的**野祭**传统。公开叙述中：**Wecheku** 为家神／户神类概念；**Tangse／tangzi（堂子）** 为堂祭／祭神空间概念；**Baichima** 等野祭／野外献祭见于研究讨论。乾隆朝曾敕纂满文本《满洲祭神祭天典礼》（1747；后有汉译本并收入《四库全书》）。本条目为教育性概览；**Wecheku**、**Tangse／tangzi**、**Baichima** 均 CONCEPT——shaman/elders host only, users don't officiate。**不提供**牲礼操作、请神／附体脚本、宫廷祷词全文复诵教程。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常理解为通过定期献祭、祝祷与满语祝辞，向天、佛菩萨（宫廷层曾纳入）及氏族神灵求福、报恩与禳灾。公开研究强调：礼仪中心往往是「献与祝」而非以出入神为唯一目的；野祭中的通神可被理解为请神受祭的手段。功德贴近：氏族按时举行家祭、尊重萨满（*saman*）职分、不以汉语随意替代本应用满语的祝辞传统。访客的「福」体现为参观博物馆／宫殿解说，而不擅自「扮演萨满」——**users don't officiate**。

## 典型仪式

### 1. Wecheku 家神／户神（CONCEPT）
- **场合**：岁时应祭、祈福报赛与家庭／氏族家祭公开叙述。
- **主要步骤（概念层）**：理解 **Wecheku** 作为家神／户神类概念与家祭框架。**CONCEPT**；不提供器物摆位操作单。
- **物品**：神杆、香案、祭器外观（博物馆／图录层）。
- **谁来举行**：氏族萨满／长者；**shaman/elders host only — users don't officiate**。

### 2. Tangse／tangzi 堂子供奉（CONCEPT）
- **场合**：宫廷曾在堂子（*tangse*）与坤宁宫等处举行；氏族堂祭空间概念。
- **主要步骤（概念层）**：历史与研究概括击鼓、祝祷、献牲献糕酒、满语祝辞等框架。**Tangse／tangzi** 仅 CONCEPT；文本化宫廷典礼作文献／博物馆研究。
- **物品**：礼书图录中的祭器插图。
- **谁来举行**：历史宫廷职司／氏族承认者；今仅作文献与博物馆研究。

### 3. Baichima 野祭／野外献祭（CONCEPT）
- **场合**：不定时的治病、驱邪、求护等；涉及特定动物或英雄神灵的公开研究讨论。
- **主要步骤（概念层）**：**Baichima** 仅 CONCEPT；说明鼓乐、舞蹈、祝请与通神表演见于民族志。**不提供**诱导附体或驱邪操作步骤。
- **物品**：神鼓、神裙等外观（展览层）。
- **谁来举行**：受氏族承认的萨满／长者；**users don't officiate**。

## 日常与节庆

当代东北满族社群中，家祭传统在各地保存程度不一，并与汉俗、藏传佛教因素交错。旅游「萨满表演」须与真正氏族祭祀权区分。

## 注意与尊重

**勿把**通神／附体做成娱乐关卡。勿擅自复建「野祭」并公开售票。勿把《祭神祭天典礼》简化为可下载「咒语包」。涉及活态氏族祭祀时，优先本族组织与研究者口径。**Shaman/elders host only; users don't officiate.**
