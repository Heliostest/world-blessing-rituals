# 马绍尔群岛传统信仰与航海祈福余绪（Marshallese／Aelōñ Kein）

## 概述

**马绍尔人（Marshallese）** 是中太平洋密克罗尼西亚东部马绍尔群岛（Majōl）的原住民族群。公开材料记述：传统事务上有 **Iroij／Iroijlaplap** 酋长层与 **Weto** 氏族土地习惯；**Kāāitōk／Wāwa** 等棍图（stick charts）为波浪—航路教学模型；自然灵 **Nonieb** 等见于民俗叙述；当代公共庆祝可见 **Kemem／Kamool** 等社区庆生／里程碑聚会。今日以基督教为主，密克罗尼西亚神学院等综述指出航海、造舟与收获曾伴有对守护灵的祈祷。本条目为教育概览；航海祝福 CONCEPT；棍图与酋长层 viewing／CONCEPT——**users don't host chiefly rites**。**不提供**附体诱导、占卜操作或唤灵步骤。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

传统层的祈福常被理解为：通过敬畏礁盘与 **Nonieb** 等自然灵 CONCEPT、向海与舟船守护灵求助，并在 **Iroij**—**Weto** 秩序中分担土地与航海责任，使航行与渔捞平安。**Kāāitōk／Wāwa** 棍图承载波浪知识教学，而非游客可「主持」的开光物。功德贴近：妥善送别亡者、遵守地点禁忌。访客的「福」体现为：把马绍尔航海文明与核时代正义诉求一并认真对待——**users don't host chiefly rites**。

## 典型仪式

### 1. Kāāitōk／Wāwa 棍图与航海祝福（概念／文化层）
- **场合**：航海知识传习、博物馆／教育展示；历史造舟出航祈祷叙述。
- **主要步骤（概念层）**：理解棍图作为岸上教学模型（波浪、岛位）；当代公开下水祝福服从主办社区。**止于历史—文化解释**；不提供咒词或可复现「导航开光」。
- **物品**：棍图外观（博物馆／展览）、帆舟外观。
- **谁来举行**：传统知识持有者与氏族；外人不可擅自主持。

### 2. Iroij／Iroijlaplap 与 Weto 氏族土地（CONCEPT／习惯法层）
- **场合**：酋长咨议会与习惯法土地事务的公开制度叙述。
- **主要步骤（概念层）**：理解 **Iroij** 酋长权威与 **Weto** 氏族地权为社群内部秩序。**CONCEPT**；**禁止**游客主持酋长仪礼——**users don't host chiefly rites**。
- **物品**：从略。
- **谁来举行**：Iroij 与氏族；外人不得僭越。

### 3. Nonieb、Kemem／Kamool 与丧礼禁忌（概念／公共交界）
- **场合**：自然灵民俗叙事；社区 **Kemem／Kamool** 庆生与里程碑公开聚会；亲属丧礼。
- **主要步骤（概念层）**：**Nonieb** CONCEPT；Kemem／Kamool 止于获准社区庆祝 viewing；丧礼与地点禁忌仅 CONCEPT，**禁止**附体诱导。
- **物品**：从略。
- **谁来举行**：家族与教会；酋长相关仪礼由社群内部主持。
