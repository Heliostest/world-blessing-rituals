# 翁通爪哇传统信仰与环礁—基督教祈福（Ontong Java／Luangiua）

## 概述

**翁通爪哇（Ontong Java；亦称 Luangiua）** 为所罗门群岛北部大型环礁，居民语言文化属波利尼西亚外岛传统。公开记述：基督教占主导，同时祖先记忆与严格海洋—资源伦理维系环礁生存；海平面上升使气候正义进入公共祈祷叙述。本条目为教育概览；**不提供**历史献牲或可冒充首领的步骤。与伦内尔—贝罗纳、提科皮亚、阿努塔条目可比较但环礁生态与历史独立。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：在教堂礼仪中求护佑，并通过分享与海洋禁忌维持环礁繁荣。功德贴近：支持气候适应与社区主导的研究伦理。访客的「福」体现为：**默认少去**，听从地方许可。

## 日常与节庆
