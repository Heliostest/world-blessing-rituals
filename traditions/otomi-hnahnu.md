# 奥托米／尼亚纽传统信仰与圣石祈福（Otomí／Hñähñu）

## 概述

**奥托米人（Otomí；自称常作 Hñähñu／Ñähñu 等，支系与自称因地而异）** 为墨西哥中部奥托—曼格语系民族，分布于梅斯基塔尔高原、托卢卡谷地至东部山地等广大区域。公开宗教学条目（encyclopedia.com《Otomí Religion》）指出：殖民以来形成以天主教为主、又保留双元对立与地方宇宙观的**交融宗教**；礼仪生活常环绕父系地方崇拜、农作丰饶与祖先，圣所（洞穴、山、圣石）与教堂并置。梅斯基塔尔等地公开研究强调 **Cangandhos** 等被人格化／动物化的**圣石**，以及梦中与神性沟通的叙事；东部山地则有知识持有者 **bädi** 以剪纸形象、梦的解读等公开记述的技术调解「他界」力量与 **nzáki**（生命力）平衡。本条目为教育概览；**不提供**剪纸仪式操作、出神诱导、献牲步骤或任何可冒充 bädi 的程序。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：在圣石、山灵、圣徒与祖先交织的世界中，通过供奉、节庆与梦的伦理倾听，恢复身体—土地—社群的平衡。功德贴近：维护地方圣处与堂区责任、参与丰饶礼仪的公共层面、拒绝盗卖圣石。访客的「福」体现为：承认奥托米不是「已被完全同化的农民」，其象征体系具有独特双元逻辑。

## 典型仪式

### 1. 圣徒瞻礼与民间天主教节庆（公共层）
- **场合**：主保圣人日、天主教日历节庆。
- **主要步骤（概念层）**：弥撒、游行、宴饮；公开材料指出圣徒形象有时可「掩护」更古老的神性叙事。**止于概念**。
- **物品**：教堂与花饰外观（概念）。
- **谁来举行**：堂区与mayordomía 类职务持有者。

### 2. 圣石／Cangandhos 敬礼（部分敏感）
- **场合**：地方圣石与梦中启示叙事。
- **主要步骤（概念层）**：理解圣石作为神性「使者」的公开宇宙观。**禁止**盗取、买卖或搬动圣石。
- **物品**：从略。
- **谁来举行**：家庭与地方承认者。

### 3. bädi 知识与剪纸／梦的调解（高度敏感，仅概念）
- **场合**：疾病、丰饶危机与「他界」交涉的公开学术记述。
- **主要步骤（概念层）**：仅说明剪纸形象与梦释作为概念。**禁止任何操作教程**。
- **物品**：从略。
- **谁来举行**：bädi；外人不得模仿营利。

## 日常与节庆

奥托米各地区差异大（高原与山地）。写作应优先 encyclopedia、INAH 等公开学术与奥托米人自身叙述，避免把剪纸艺术从礼仪语境中完全剥离为纯手工艺商品——亦可购买当代工艺品，但勿声称「真仪」。

## 注意与尊重

**勿盗掘或购买「真圣石」。** 勿把剪纸仪式做成工作坊「附体体验」。拍摄圣地须征得同意。勿将奥托米与普雷佩查、米斯特克条目混同。

## 手机互动适合度（Three.js 评估草稿）

- **档位：** C 可做致敬小品（非真仪）
