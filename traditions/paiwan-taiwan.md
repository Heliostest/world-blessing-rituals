# 台湾排湾族传统信仰与祭仪（Paiwan／Payuan）

## 概述

**排湾族（Paiwan／Payuan）** 主要分布于台湾南部大武山两侧（屏东、台东一带），以家名、贵族阶层与精湛雕刻、琉璃珠、陶壶文化著称。中华民国原住民族委员会等公开资料指出：传统信仰核心为 **tsemas**（神灵／祖灵／自然灵等超自然存在），并由祭司 **palakalai** 与巫师 **malata** 沟通善恶灵与祖先。重要岁时仪礼包括小米收获感恩祭 **Masalut**；拉瓦尔／武鲁群等支系中，部分部落每五年举行迎接大武山祖灵的 **Maljeveq**（五年祭，亦称人神盟约祭）。日治时期传统受压制；二十世纪中叶以降基督宗教广泛进入部落，今日教会与传统祭仪常并存。本条目为教育性概览；**不提供**巫师通灵脚本、贵族禁忌操作或可复现召灵祷词。

公开文化记述突出 **Masalut** 小米收获感恩祭、**Maljeveq／Djemuljat** 五年祭刺球（ball-piercing）公共竞技外观——须以强烈原住民尊重表述、**Puringau** 相关礼仪 **CONCEPT ONLY**，以及 **Naqemati** 祖灵柱／祖先柱文化象征。**一律不提供 how-to**（无通灵、无祭词、无刺球真仪复现教程）。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：向祖灵（vuvu）与各方 tsemas 求平安、丰收、健康与家屋延续；饮酒前以右手食指弹酒敬祖等日常姿态，体现与祖先的亲近。公开材料区分善灵赐福与恶灵致灾，并强调头目、贵族、祭司／巫师与平民的阶层职分。功德贴近：履行收获祭与五年祭义务、尊重贵族纹饰与圣地、在祭仪中听从祭司与巫师安排。访客的「福」体现为：受邀观礼时遵守摄影与场地规则，不擅自「召祖灵」。

## 典型仪式

### 1. 小米收获感恩祭 Masalut（概念层）
- **场合**：小米收获後的年度关键祭；贯穿耕种各阶段亦有配套礼仪。
- **主要步骤（概念层）**：原民会公开概述包括贮谷祈福、选种、头目会同巫师祭司巡视各户收成，并以部分收获献于祖灵屋等。**仅概念介绍**；不提供祭词逐句教程。
- **物品**：小米、谷仓、祖灵屋外观。
- **谁来举行**：头目、祭司、巫师与部落成员。

### 2. 五年祭 Maljeveq／Djemuljat 刺球（概念层，强烈原住民尊重）
- **场合**：武鲁群部分部落约每五年一次；迎大武山祖灵访子孙。
- **主要步骤（概念层）**：公开记述含净场、备刺球架与藤球（qapudrung）、迎灵娱灵、刺球、驱邪、宴饮与送灵等阶段。**仅概念介绍**；刺球为圣约／丰收象征的公共竞技外观，**严禁写成嘉年华游戏摊位或 how-to 教程**。
- **物品**：刺球架、竹竿、藤球、祭品外观（概念）。
- **谁来举行**：该部落祭司、巫师、头目贵族与战士；游客仅在开放观礼时遵守现场规则。

### 3. Puringau CONCEPT ONLY 与 Naqemati 祖灵柱（高度敏感／象征层）
- **场合**：部落内部礼仪命名；家屋／部落空间中的祖先柱（Naqemati）文化象征。
- **主要步骤（概念层）**：Puringau **仅 CONCEPT ONLY**——命名与尊重，**无操作步骤**。Naqemati 祖灵柱作为雕刻／空间象征的公开文化层介绍，**禁止**复现立柱仪轨或冒用贵族纹饰。
- **物品**：祖灵柱外观（概念）。
- **谁来举行**：有职分之部落成员；外人不得模仿营利。


## 日常与节庆

当代排湾族人多同时参与教会生活与文化复振；五年祭在部分部落（如土坂 Tjuabal、古楼 Kuljaljau 等公开报道提及者）仍具高度可见度。尊重各部落对观礼、纹饰使用权与祖灵屋的规范，以及台湾原住民族权利与文化资产相关法律。

## 注意与尊重

**勿把五年祭刺球写成嘉年华游戏摊位。** 勿模仿巫师通灵或冒用百步蛇等贵族纹饰。涉及丧葬、驱邪与贵族禁忌时，仅作概念层理解。优先各排湾部落与原住民族委员会口径。

## 手机互动适合度（Three.js 评估草稿）

- **档位：** C 可做致敬小品（非真仪）
- **敏感度：** 中
- **判断：** 巫师通灵与祖灵召请不可互动化；但公开五年祭中的刺球环节具有可辨识的公共竞技外观，适合做成明确标注为「手势练习」的致敬小品，而非真仪通关。取 C：可做短时陀螺／拖拽刺球练习，并强制说明卡。
- **若做成互动：** 手势练习：① 缓慢旋转观看石板屋与刺球架说明卡；② 拖拽瞄准，用虚拟竹竿轻触落下的藤球（不命名为 Maljeveq 通关）；③ 陀螺仪稳定「端握」说明卡上的小米意象；④ 写下自己对丰收／健康的一句祝福（本地保存，不模拟祭词）。全程标注致敬练习。
- **红线：** 禁止模拟 malata 通灵、召祖灵、驱邪、冒用贵族纹饰／头目身份，或以 Masalut／Maljeveq 真仪名称作胜负。
