# 塞托东正教与民间祈福传统（Seto／Setomaa）

## 概述

**塞托人（Seto；地区称 Setomaa）** 为分布于今爱沙尼亚东南与俄罗斯边境一带的波罗的芬兰语东正教群体，常被主流东正教语境称为「半信徒」——因同时保持丰富的前基督教民俗。国家地理等公开报道记述：圣母安息等瞻礼、**Pechory／佩乔雷（佩谢里）修道院**相关游行，以及墓园纪念共餐；民俗记忆中亦有守护者／英雄 **Peko** 的口述层（**folk memory**，非操作祭仪）。联合国教科文组织将塞托多声部歌唱传统 **Leelo** 列入人类非物质文化遗产代表作名录。与东正教亡者纪念日历相关的 **Radonitsa** 类墓园共餐亦见于公开文化记述。本条目为教育概览；**不提供**可冒充圣事的操作，亦不鼓励惊扰墓地的模仿游戏。与本档案「爱沙尼亚地信仰」条目为**平行传统**。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：在东正教斋期与圣人日历中，通过弥撒、圣像敬礼、施舍与墓园共餐，维持活人与亡者的互惠；Leelo 歌唱母亲传承则巩固族群声音认同；Peko 属于民俗记忆而非可通关的「神祇收集」。功德贴近：守斋与堂区义务、跨境探亲朝圣、教授 Leelo。访客的「福」体现为：尊重边境分隔下的探亲与宗教自由，勿把塞托写成「童话王国」消费品。

## 典型仪式

### 1. Pechory 修道院游行与东正教瞻礼（公共层）
- **场合**：圣母安息等大瞻礼；佩乔雷／Pechory 修道院相关圣像巡行与祝福。
- **主要步骤（概念层）**：弥撒、游行、神父祝福。**非信徒勿领圣餐**。
- **物品**：圣像与修道院外观（概念）。
- **谁来举行**：教士与朝圣者／会众。

### 2. Radonitsa 类墓园共餐纪念（部分敏感）
- **场合**：变形节等瞻礼后、以及与 **Radonitsa**（亡者纪念／墓园探访日）相关的墓地聚会。
- **主要步骤（概念层）**：公开报道描述与亡者「同席」分享食物。**止于概念**；外人勿打扰丧家。
- **物品**：从略。
- **谁来举行**：家族。

### 3. Leelo 多声部歌唱与 Peko 民俗记忆（公共文化层）
- **场合**：节庆、竞赛与日常传承；口述中的 Peko 记忆。
- **主要步骤（概念层）**：教科文组织认定的领唱—合唱 **Leelo** 传统；**Peko** 仅作 folk memory 点名。**止于概念**；禁止把 Peko 写成可操作祭神教程。
- **物品**：无。
- **谁来举行**：歌唱母亲（lauluima）与歌队；口述传承者。

## 日常与节庆

塞托语与服饰、厨房文化是认同核心；边境管控改变朝圣路线。优先 UNESCO、National Geographic 公开报道与塞托人自身组织叙述。

## 注意与尊重

**勿在墓园野餐式嬉闹。** 勿未经许可录音 Leelo 商用。跨境旅行遵守签证与圣地规定。勿与「马阿乌斯克」复兴运动混为一谈。
