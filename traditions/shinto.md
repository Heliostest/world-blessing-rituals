# 神道

## 概述

神道以神社为中心，敬奉被称为神明（*kami*）的神圣存在——可与自然力、祖先英灵或地方守护相关。对许多人而言，祈福并非抽象教义辩论，而是透过**手水舍（Temizuya／Chōzuya）洁手**、**参拜（sanpai）**、**祓除**、取得 **御守（omamori）／神札（ofuda）／绘马（ema）**、参加 **初诣（hatsumōde）** 与祭礼 **神乐（kagura）** 来更新与神明的关系。日本战后由神社本厅推动的参拜规范——**二拜二拍手一拜（2-2-1）**——广为人知，但历史上层层叠叠的古式仍在个别神社留存。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

神道重视清净、感谢与和谐。参拜首先是问候与报告，伴随赛钱与鞠躬拍手；愿望可以陈说，却不宜简化为“投币买效果”。御守与神札承载神社神威，针对交通安全、学业、安产等主题提供守护象征。神乐以乐舞慰神，使神明欢喜停留。年的更新——尤其正月初诣——被视为净化与重新开始的契机。所谓福运，常与正直、礼节与社区祭礼参与相连。

## 典型仪式

### 1. Temizuya 与参拜 sanpai（二拜二拍手一拜）
- **场合**：日常路过问安、考试或疾病时的祈愿、节庆参拜。
- **主要步骤（概念层）**：于 **Temizuya／手水舍** 洁手漱口；通过鸟居时点头示敬；至拝殿投赛钱；正式场合可奉玉串；一般信众行 **二拜、二拍手、一拜（2-2-1）**；默祷后退出。教育概览层说明公开礼节，**非**冒充神职教程。
- **物品**：赛钱；玉串由神职在正式祭祀中使用。
- **谁来举行**：个人随时可参拜；正式祭祀由宫司等神职主持。

### 2. 御守 omamori、神札 ofuda 与绘马 ema
- **场合**：初诣、人生转折、旅行出发前。
- **主要步骤（概念层）**：在社务所说明需求并领受 **omamori／ofuda**；奉持于包中或神棚；旧物多在年末岁末返还神社焚纳，而非随意丢弃。**绘马（ema）** 书写愿望悬挂。
- **物品**：御守、神札、绘马、御神签。
- **谁来举行**：神社授与；信众奉持。

### 3. 初诣 hatsumōde 与神乐 kagura
- **场合**：正月 **hatsumōde** 人潮最大；例祭、奉纳祭、特定神社的定期神乐公演。
- **主要步骤（概念层）**：初诣时祈年、换御守、抽签；**神乐（kagura）** 以乐舞慰神，观者肃静，不随意走动穿越舞区。理解其为公开祭礼文化，**不模仿秘祭**。
- **物品**：神乐铃、面、装束、笛鼓等外观（概念）。
- **谁来举行**：神职或社中传习之舞人；部分被指定为文化财；初诣为广大信众。

## 日常与节庆

正月初诣人潮最大。七五三、成人、婚礼前的祈愿，以及地镇祭等土木相关净化，亦属常见。家庭可设神棚供神札，但大规模祭礼仍在神社举行。

国学院大学《神道事典》指出，一般参拜的二拜二拍手一拜是战后普及的标准，而伊势等地仍保留八度拜等古式。认识神道祈福，需要同时看见通行礼与地方差歧，避免以单一旅游手册覆盖全部神社传统。

## 注意与尊重

各社对摄影、饮食、宠物与禁地规定不同，应观告示。神乐与某些秘祭不可擅自模仿。御守勿拆开“看里面”，废旧应返还。作为游客，勿干扰婚礼专用时段或祭典行列。

## 手机互动适合度（Three.js 评估草稿）

- **档位：** C 可做致敬小品（非真仪）
- **敏感度：** 低
- **判断：** 参拜含手水、赛钱、二拜二拍手一拜与绘马书写，属神社对访客公开的短礼仪。神乐与秘祭不可模仿，但庭前参拜姿态适合手机致敬小品。
- **若做成互动：** 手机手势练习（致敬小品，非神社正式参拜）：

1. 陀螺仪微鞠躬：走近鸟居前轻轻低头示意。
2. 点按投入虚拟赛钱，听一声轻响（不称“完成参拝”）。
3. 拖拽书写短愿并挂上绘马形木牌。
4. 双指轻拍两次后点头一次，界面标题用原创名如「庭前一礼」。
- **红线：** 不模仿神乐秘祭、拆开御守，不以“参拝成功／通关”或神社正式仪名作胜负。
