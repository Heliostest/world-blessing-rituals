# 泰国神屋／土地灵（San phra phum / phi）

## 概述

在泰国城乡，住宅、商铺与公共建筑旁常见架于柱上的微型殿宇，泰语称 **ศาลพระภูมิ**（*san phra phum*，常译「神屋」或「土地神龛」）。它们被视为土地守护灵（*phra phum*）或地方灵（相关概念亦涉 *chao thi*／*jao tee* 等）的居所，与广泛的 **ผี**（*phi*，灵／鬼）信仰相连。多数泰国人同时自认上座部佛教徒：神屋供养并不取代寺院功德，而是处理「此地是否安居」的日常关系。公开可见供养常含 **น้ำแดง（Nam Daeng，红水／甜红饮）** 与 **พวงมาลัย（Phuang Malai，花环）**；新居／营业前的 **ขึ้นศาล（Khuen San）** 安放与 **หมอขวัญ（Mor Khwan）** 等礼俗顾问参与仅作 **CONCEPT ONLY**。曼谷 **Erawan／四面神** 等公共神社则是游客亦可旁观的城市地标礼敬。康奈尔大学等民族志指出，都市中常见的 *san phra phum* 与供奉地方／祖先灵的 *san chao thi* 不宜混为一谈。本条目为教育性概览，说明访客可见的供养结构，**不提供**安座、迁龛、请灵或 Khuen San／Mor Khwan 的可复现仪式步骤。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

核心观念是：土地先有灵力「主人」，人若占用空间，需以尊重与定期供养维持互惠，以求平安、生意顺利与家宅和谐。祈福指向安抚与感通守护灵，避免因忽视而招致不安。功德在佛教语境仍主要透过布施僧团、持戒与禅修累积；神屋实践则更近「地方礼仪」——正确安放、清洁与供品被认为维持关系本身。公开报导强调，安放位置与吉时往往请熟悉礼俗者或僧人参与咨询；日常则由住户或店员上香献供。泰国宗教研究亦指出，神屋中可见印度教神祇小像等多元象征，反映婆罗门—佛教—本土灵观的长期交织。

## 典型仪式

### 1. 日常供养：Nam Daeng 与 Phuang Malai（访客可见层）
- **场合**：清晨或约定时辰，于住家／店铺神屋前。
- **主要步骤（概念层）**：清洁龛前；献 **Phuang Malai（花环）**、果食、甜点与 **Nam Daeng（红水／甜红饮）** 等常见供品；点香烛；合十致意。公开文化叙述止于此；**不描述**请灵咒语或安座程序。
- **物品**：香、花环、水果、甜点、Nam Daeng 等。
- **谁来举行**：住户、店员；大型物业或有专人负责。

### 2. Khuen San／Mor Khwan 安放与礼俗咨询（CONCEPT ONLY）
- **场合**：动土、开业、乔迁前后。
- **主要步骤（概念层）**：向土地灵告知使用意图、择地安放神屋（**ขึ้นศาล／Khuen San**），并可能咨询熟悉礼俗者或 **หมอขวัญ／Mor Khwan** 等顾问。**CONCEPT ONLY**——细节属专业／地方知识，本档案仅承认其存在，禁止操作教程。
- **物品**：新神屋、基础供品与礼敬用品（概念）。
- **谁来举行**：熟悉礼俗的顾问、僧人或家庭长辈指导；业主参与。

### 3. Erawan／四面神等公共神社礼敬（概念层）
- **场合**：曼谷 **Erawan Shrine（四面神）** 等著名公共崇拜点；游客亦可旁观献舞与花环。
- **主要步骤（概念层）**：献花、点香、许愿；有时有传统舞蹈还愿表演。此为公共空间中的可见礼敬，仍非私人神屋安座教程。
- **物品**：花环、香、蜡烛。
- **谁来举行**：信众与游客在管理人员指引下；舞蹈多为受雇表演者。

## 日常与节庆

神屋几乎是泰国街景的一部分：从高档餐厅到巷口摊贩皆可见。供品种类随流行文化变化，但「先敬土地再安居」的逻辑持续。与寺院礼佛、家中佛坛并行，形成叠合的宗教生活。游客常误拍、误触或嘲笑微型建筑，易构成不敬。

## 注意与尊重

勿触摸、移动或拍摄时挡住他人供养；勿擅自取走供品「当纪念品」。勿要求演示安座、迁灵或驱邪步骤。讨论 *phi* 时避免猎奇鬼片化，亦勿以「迷信」贬低与佛教并存的地方礼仪。涉及动物献祭的历史或边缘实践，本档案不提供任何操作说明。
