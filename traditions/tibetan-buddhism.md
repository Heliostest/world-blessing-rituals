# 藏传佛教

## 概述

藏传佛教流传于青藏高原、蒙古高原、喜马拉雅周边及全球侨民社群，显密并蓄。对普通信众而言，日常积德与祈福方式包括：**转经筒（mani）、磕长头／大礼拜、绕圣（kora）、风马旗（lungta）、放生**，以及 **Chöme（酥油灯）** 供灯；圣月 **Saga Dawa** 尤为集中。这些行动强调以身语意恭敬三宝，并把利益回向给一切有情。朝圣路线——如绕转圣地——本身即是长时段的祈祷。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

功德来自清净动机、持咒念诵与身体力行的礼拜。转经筒（*mani khorlo*）内装满经咒，顺时针转动传统上被视为等同多次念诵。风马旗（*lung ta*，风马）借风力把经咒与祈愿带向虚空，象征福运上扬。磕长头用以对治我慢、净化身语意。绕圈（*kora*）把朝圣变成行走中的禅修。整体上，祈祷与皈依、上师相应、慈悲心（菩提心）结合；密法灌顶则另有誓言与师徒规范，不属于旅游式体验。

## 典型仪式

### 1. 转经筒 mani、磕长头与绕圣 kora
- **场合**：寺院转经廊、朝圣途中；圣地累拜与绕山绕寺。
- **主要步骤（概念层）**：保持正念顺时针转动 **mani** 转经筒；大礼拜合掌俯伏前进；**kora** 绕行圣地。教育概览层的公开实践说明。
- **物品**：转经筒、念珠、护膝／护手等外观（概念）。
- **谁来举行**：僧俗皆可；朝圣者个人或结伴。

### 2. 风马旗 lungta 与放生
- **场合**：山口垭口、寺院周边、圣湖圣山；节日放生亦盛。
- **主要步骤（概念层）**：悬挂五色 **lungta**（风马旗）；放生时依上师或寺院开示进行。注意：苯教传统绕行方向常相反，不可混用场所规矩。
- **物品**：风马旗、念珠。
- **谁来举行**：当地信众与朝圣者。

### 3. Saga Dawa 与 Chöme 酥油灯（节庆／日常层）
- **场合**：圣月 **Saga Dawa**；日常与节日供灯。
- **主要步骤（概念层）**：理解 Saga Dawa 期间朝圣、戒杀放生与功德尤为集中；以 **Chöme（酥油灯）** 供灯表恭敬与回向。**止于公开文化概念**；灌顶密续另有限制。
- **物品**：酥油灯／供灯。
- **谁来举行**：信众与僧团；大型法会由上师主导。

## 日常与节庆

日常：转经、供灯、持咒、放生、供养僧团。萨嘎达瓦等圣月，朝圣与戒杀放生尤为集中。传召法会、灌顶大法会需具格上师。家庭中亦可设经堂，但唐卡与佛像安置有传统礼节。


在喜马拉雅艺术与博物馆叙述中，转经被视为把书面咒语转化为动态慈悲的技术；信徒强调发心端正，机械转动本身仍需正念配合。当代亦见电动转经筒，传统上对其功德解释仍回归动机与皈依。

## 注意与尊重

灌顶、密续生起／圆满次第、某些护摩与迁识引导属于誓言限制内容，本档案仅作名目层介绍，不提供修习步骤。勿擅自拍摄天葬、闭关处或禁止摄影的殿堂。风马旗与玛尼石堆有神圣含义，不宜当作纯装饰随意丢弃或踏越。

## 手机互动适合度（Three.js 评估草稿）

- **档位：** C 可做致敬小品（非真仪）
- **敏感度：** 中
- **判断：** 转经筒顺时针转动为僧俗皆可的公开实践；磕长头与风马亦常见于朝圣道。灌顶密续则严禁。取转经／挂旗致敬为 C。
- **若做成互动：** 手机手势练习（致敬小品，非灌顶修法）：

1. 手指滑动使转经筒顺时针旋转。
2. 陀螺仪配合缓步沿廊道前进。
3. 拖拽挂起一面五色风马旗。
4. 标题如「廊前轻转」，不宣称念满咒语通关。
- **红线：** 禁止灌顶、生圆次第、天葬拍摄或苯／佛绕行方向混用误导；密续名不作胜负。
