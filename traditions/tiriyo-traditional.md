# 蒂里奥传统信仰与圭亚那盾祈福（Tiriyó / Trio）

## 概述

**蒂里奥人（Tiriyó，亦作 Trio）** 分布于苏里南、巴西与圭亚那交界的圭亚那盾雨林。公开叙述涉及村落礼仪、成年礼与护佑观念——**极高敏感，本卡仅概念层**。今日并存基督教接触与跨境土地议题。教育概览；**严禁**入会细节或可冒充仪者的步骤。与瓦亚纳、阿帕莱等条目区分；不另开 trio 同义卡。

## 核心观念（祈福 / 功德 / 祈祷如何被理解）

祈福常被理解为：通过对河岸生态、祖先与仪式专家伦理的正确关系，求健康与农猎顺利。功德贴近：支持跨境原住民权利。访客的「福」体现为：**非邀莫入**。
